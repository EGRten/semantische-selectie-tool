# Concordans niet heruitgegeven

De externe Excel-concordans en de JSON die alle oorspronkelijke cellen daarvan overneemt zijn niet opgenomen. Voor deze zelfstandige tabel zijn geen onbeperkte herpublicatierechten vastgesteld. Dit is geen verwijdering van de drie officiële datasets: alle zelfstandig tegen primaire bronnen gecontroleerde selectiegegevens en hun IDs zijn behouden.

Broncontext: https://www.vhic.nl/faq/selectielijsten-2017-en-2020/ . De metadata en oorspronkelijke hash staan in bronnen/concordans-aangeleverd.bron.json. De verwijzing bewijst niet dat dit exacte bestand daar nog rechtstreeks kan worden gedownload.
